# Contributing

Thanks for working on the Intelligence Fusion Platform.

## Workflow

1. Pull the latest changes: `git pull origin main`
2. Create a branch: `git checkout -b feature/short-description`
3. Make your changes and run the tests: `./start.sh --test`
4. Commit with a clear message: `git commit -m "feat: short description"`
5. Push and open a pull request: `git push -u origin feature/short-description`
